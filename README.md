# 🏡 Find Your Dream Home — Real Estate Web App

A beautiful, modern, mobile-first real estate web application built with **HTML**, **Tailwind CSS**, and **vanilla JavaScript**. Discover villas, apartments, and bungalows across **Ratnagiri** and **Chiplun** — with live search, smart filters, glassmorphic UI, and a premium 3D balloon button design.

---

## 📸 Preview

> A sleek, phone-shaped UI with glass bottom navigation, animated active pills, glass-effect badges, and detailed property pages.

---

## ✨ Features

### 🎨 Design
- **Mobile-first** phone-shaped container (works perfectly on desktop too)
- **Glassmorphism** bottom navigation with frosted blur & specular highlights
- **3D balloon buttons** with glossy shine for primary CTAs
- **Glass-effect property badges** ("For Rent" / "For Sale")
- **Smooth screen transitions** with fade-in animations
- **Phosphor Icons** for a modern, clean look

### 🔍 Functionality
- **Live search** — Type "Ratnagiri" or "Chiplun" to instantly filter properties
- **Smart filters** — Filter by Sale, Rent, Bunglow, or Apartment
- **Combined search + filter** — e.g. search "Ratnagiri" + click "Sale" to see only Ratnagiri properties for sale
- **Dynamic property cards** — Each card shows villa name, price, location, beds, baths, and square footage
- **Property details page** with working tabs:
  - **Overview** — Description of the property
  - **Amenities** — Wi-Fi, Pool, Parking, AC, Kitchen, TV, Washer, Security, Garden, Gym
  - **Location** — Map, full address, nearby landmarks (airport, railway, hospital, shopping)
  - **Policies** — Check-in/out, No Smoking, Pets, Cancellation, ID requirements
- **Empty state** — Friendly "No Properties Found" message when filters don't match
- **Reset-friendly** — Clear search with one tap
